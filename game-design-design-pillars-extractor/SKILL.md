# Game Design Design Pillars Extractor

Extract actionable design pillars from mechanics and tradeoffs when stated pillars are vague, generic or contradictory.

## Design lens

A meaningful design pillar does two things:
- names what the design is trying hard to deliver
- implies what the design is willing to sacrifice to deliver it

If a pillar does not create a constraint, it is not a pillar yet.

## Result

- **Extracted pillars** - 3 to 5 clear, testable pillars
- **Support map** - which systems actually reinforce each pillar
- **Conflict map** - where systems or candidate pillars push against each other
- **Missing or weak dimensions** - important priorities that are undefined, accidental, or under-supported
- **Decision guidance** - which pillars should dominate future choices
