# Game Design Five Options

Develop and compare five game-design approaches when the user wants a deliberately broader option set before choosing.

## Result

- **Problem statement** - what needs solving
- **Five options** - distinct solution directions
- **Pros and cons** - the upside and downside of each
- **Rough comparison** - impact, cost, and fit
- **Recommendation** - the best option or best test candidate

The five-way comparison is the requested method, not arbitrary padding. Make the alternatives meaningfully distinct and compare their tradeoffs.
